# astrbot_plugin_ai_delay

一个让机器人回复更像真人的 AstrBot 插件：AI 回复有随机延迟，连发的多条消息会自动合并成一条一起回复。

## 它解决什么问题

- **秒回像人机**：真人打字需要时间，本插件让 AI 回复前随机等待一段时间，更像真人
- **发一句回一句**：用户连发好几条消息时，机器人不等全部发完就逐条回复，很生硬。插件会等用户停顿后，把连发的消息**合并成一条**一起发给 AI，只回复一次
- **表情包被无视**：纯图片/表情包消息也能参与合并（以 `[图片]` 占位），AI 能正常回应表情包

## 功能

- 随机延迟：AI 回复前随机等待（默认 10~40 秒，可配置）
- 消息合并窗口：滑动窗口机制，用户连发消息时自动等待、合并、只回一次
  - 纯图片/语音/视频消息以 `[图片]`、`[语音]`、`[视频]` 占位符参与合并
  - "对方正在输入"等无内容事件自动忽略，不占用窗口、不触发回复
- 双豁免名单（互相独立，按用户 ID 配置）：
  - **免延迟名单**：名单内用户 AI 回复不延迟
  - **免合并名单**：名单内用户消息不参与合并等待
- 自动过滤模型复述的工具调用文本（如 `[调用工具 xxx]`），避免泄露到聊天
- 只对 AI 对话生效，普通指令（如 /help）不受影响

## 安装

- **方式一**：AstrBot WebUI → 插件市场 → 搜索 `ai_delay` 安装
- **方式二**：WebUI → 插件管理 → 从仓库安装，填入本仓库地址
- **方式三**：手动克隆本仓库到 AstrBot 的 `data/plugins/` 目录，重载插件

## 配置

在 WebUI「插件管理 → AI回复随机延迟 → 插件配置」中设置：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 最小随机延迟（秒） | AI 回复前等待时间下限 | 10 |
| 最大随机延迟（秒） | AI 回复前等待时间上限 | 40 |
| 免延迟用户ID列表 | 这些用户的回复不延迟 | 空 |
| 消息合并窗口（秒） | 连发消息的合并等待时间，滑动窗口机制；0 关闭合并 | 5 |
| 免合并用户ID列表 | 这些用户的消息不参与合并等待 | 空 |

用户 ID 可通过聊天指令 `/sid` 获取。

## 测试

聊天中发送 `/延迟测试`（或 `/delaytest`），会模拟一次随机延迟回复，并显示你的用户 ID 和白名单状态。
