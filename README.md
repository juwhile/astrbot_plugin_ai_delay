# astrbot_plugin_ai_delay

AstrBot 插件：AI 回复随机延迟，让机器人的回复更像真人。

## 功能

- 普通用户触发 AI 回复时，随机延迟一段时间后发送（默认 10~40 秒，可配置）
- 消息合并窗口：用户连发多条消息时，等一段时间无新消息后，把所有消息拼接成一条一起请求 AI，只回一次（避免逐条回复像人机）
  - 纯图片/语音/视频消息以 `[图片]`、`[语音]`、`[视频]` 占位符参与合并，AI 能正常回应表情包
  - "对方正在输入"等无内容空壳事件会被自动忽略，不占用窗口、不触发回复
- 白名单用户 ID 豁免，回复即时发送
- 只对 AI 对话生效，普通指令（如 /help）不受影响
- 自动过滤模型复述的工具调用文本（如 `[调用工具 xxx]`），避免发送到聊天

## 安装

将本仓库放入 AstrBot 的 `data/plugins/` 目录，重载插件即可。

## 配置

在 WebUI「插件管理 → AI回复随机延迟 → 插件配置」中设置：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 最小延迟（秒） | 随机延迟下限 | 10 |
| 最大延迟（秒） | 随机延迟上限 | 40 |
| 免延迟用户ID列表 | 白名单，这些用户回复不延迟 | 空 |
| 消息合并窗口（秒） | 连发消息的合并等待时间，滑动窗口机制；0 关闭合并 | 5 |

## 测试

聊天中发送 `/延迟测试`（或 `/delaytest`）可体验一次随机延迟，并显示自己的用户 ID 与白名单状态。
