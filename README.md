# astrbot_plugin_ai_delay

让机器人回复更像真人的 AstrBot 插件：AI 回复随机延迟，连发消息自动合并，支持群聊图片防过期缓存。

## 核心功能

- **拟真延迟**：AI 回复前随机等待一段时间，告别秒回。
- **消息合并**：用户连发多条消息时，等其停顿后合并为一条发给 AI，只回复一次。纯图片/语音/视频会以占位符参与合并。
- **群聊图片缓存**：QQ 图片 URL 易过期导致 AI 无法识别。插件会自动将群聊图片下载到本地缓存，并在 1 分钟后自动清理。
- **三层豁免机制**：
  - **群聊总开关**：可配置是否对群聊生效（关闭后群聊不延迟、不合并，仅私聊生效）。
  - **免延迟名单**：名单内用户的 AI 回复不延迟。
  - **免合并名单**：名单内用户的消息不参与合并等待。
- **静默过滤**：自动过滤模型复述的工具调用文本（如 `[调用工具 xxx]`），防止泄露到聊天。普通指令（如 `/help`）不受影响。

## 安装

- **方式一**：AstrBot WebUI → 插件市场 → 搜索 `ai_delay` 安装。
- **方式二**：WebUI → 插件管理 → 从仓库安装，填入本仓库地址。
- **方式三**：手动克隆本仓库到 AstrBot 的 `data/plugins/` 目录，重载插件。

## 配置说明

在 WebUI「插件管理 → AI回复随机延迟 → 插件配置」中设置：

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 群聊延迟与合并开关 | 开启：群聊生效；关闭：群聊不延迟、不合并，仅私聊生效 | 开启 |
| 最小/最大随机延迟（秒） | AI 回复前等待时间区间 | 1 / 5 |
| 免延迟用户ID列表 | 名单内用户 AI 回复不延迟 | 空 |
| 消息合并窗口（秒） | 连发消息合并等待时间，0 表示关闭合并 | 5 |
| 免合并用户ID列表 | 名单内用户消息不参与合并等待 | 空 |
| 群聊图片收集 | 收到图片自动下载缓存防过期（仅群聊） | 开启 |

> 用户 ID 可通过聊天指令 `/sid` 获取。

## 测试

聊天中发送 `/延迟测试`（或 `/delaytest`），会模拟一次随机延迟回复，并显示你的用户 ID 和白名单状态。
